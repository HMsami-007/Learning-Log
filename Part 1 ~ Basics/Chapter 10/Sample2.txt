LIFO principle is a principle used by Stack data type to manipulate, transfer, add ,remove or alter data in an array used by a stack. A real life application of LIFO is in the usage of plates in a cafeteria/kitchen/cabinet where a plate is kept first and then more plates are kept consecutively on top of it. So, plates are added one after another on top of it, as the plates are removed they are removed from top plate(the one added at the last) one after another and the plate at the bottom which is the first plate kept is removed at last. Similarly, in Stack, the data elements are moved, added or removed in the same manner, where the last data element added is the first one to be removed and the first data element added is the last one to be removed. This principle is used or implied through an array of data and pointers like TopPointer and BasePointer.
